# E-Commerce Sales Analytics using SQL

## Project Overview

This project is part of my SQL module in the Data Science & Analytics course.

The project uses a relational sales database containing information about customers, orders, products, employees, categories, and shipping.

SQL queries are used to explore the database, analyze sales data, and generate meaningful business insights.

## Objective

The main objective of this project is to practice SQL concepts and apply them to real-world business analysis.

The project focuses on:

- Exploring a relational database
- Analyzing sales and revenue
- Studying customers and products
- Analyzing employee and shipping performance
- Using joins and subqueries
- Applying window functions
- Creating SQL views
- Generating business insights

## Dataset

The project uses a Northwind-style relational sales database containing 10 tables:

- Customers
- Orders
- Order Details
- Products
- Categories
- Employees
- Employee Territories
- Territories
- Regions
- Shippers
